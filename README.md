# 手勢知識問答射擊 (Gesture Quiz Shooter)

用手勢控制的知識問答射擊遊戲：每題出現四個答案飛盤，用「手槍」手勢瞄準正確答案並開槍。使用 MediaPipe 做即時手部追蹤。

## 本機執行

相機只能在 `http://localhost` 或 HTTPS 下使用，請勿直接雙擊 HTML：

```bash
python3 -m http.server 8765
```

然後開啟 <http://localhost:8765>。

## 玩法

開始畫面有手勢動畫示範。

1. **擺出手槍**：食指伸直，其餘手指收起。
2. **瞄準**：移動整隻手。準星跟著指節走，所以彎手腕、轉手指不會移動準星，也不用這樣瞄準。
3. **開槍**：手腕一抖，食指快速往上一揚，再放回原位。命中位置用上揚之前的準星判定。
4. 答對 100 分 + 剩餘時間加分 + 連擊加分；回合結束會顯示每題回顧。

沒有相機時可用滑鼠（點擊開槍）或鍵盤 `1–4` / `A–D` 作答。開始畫面亦可開啟「準星停留 1.8 秒自動作答」。

## 自訂題庫

編輯 `questions.js`：每題有 `q`（題目）、`options`（4 個選項）、`answer`（正確選項索引，0 起）。遊戲每回合會隨機抽題並打亂選項。

## 射擊偵測

上揚（後座）要同時符合以下條件才會開火：

1. **手指相對手腕往上轉**：指尖相對手腕上升，或食指 3D 角度上升。手腕本身幾乎不動，所以移動整隻手去瞄準不會觸發。
2. **夠快、夠乾脆**：大部分上升要在 0.15 秒內完成。
3. **回到原位附近**：要回落上升幅度的一定比例，而且不會遠低於起點。約 90ms 後確認。

### 自動適應

- **相機雜訊**：遊戲會即時量度手部座標的抖動（光線不足或手離鏡頭太遠時會變大），並自動提高門檻，所以雜訊再大也不會自己亂開槍。雜訊太高時，預覽畫面會顯示「⚠ 光線不足或手太遠」。
- **訊號平滑**：訊號經過 3 幀中位數濾波，去除單幀抖動，但保留上揚的急升。
- **個人校準**：開始畫面按「校準上揚」，對著鏡頭做 5 次上揚，遊戲就會按你的力度和速度設定門檻，並切換到「我的校準」。校準結果保存在瀏覽器。

### 診斷

- 上揚差一點未觸發時，畫面會說明原因：
  - 幅度不夠
  - 不夠快
  - 沒有放回原位
  - 整隻手移動太多
- 按「下載手勢記錄」可以儲存最近 30 秒的手部訊號和每次嘗試的判定結果（JSON 檔），方便開發者用真實資料調整。

### 模擬測試結果（中靈敏度，乾淨／昏暗 20fps／高雜訊三種相機）

| 情況 | 結果 |
| --- | --- |
| 手靜止誤射 | 0% |
| 移動、掃過選項誤射 | ≤ 0.3% |
| 正常上揚觸發 | 97–100% |
| 力度較小的上揚觸發 | 80–100% |

## 快捷鍵

- `1–4` / `A–D`：直接作答
- `M`：音樂開關
- `R`：重新開始
- `Esc`：暫停並回到主畫面
