# Gesture Disc Shooter

一個用手勢控制的飛盤射擊遊戲，使用 MediaPipe 做即時手部追蹤。

## 玩法

1. 開啟網頁，允許相機權限。
2. 以食指瞄準飛向中心的飛盤，準星會自動磁吸附近目標。
3. 觸發方式（兩種都可以）：
   - **食指快速上揚**（推薦）：像真的開槍後座一樣，食指快速往上抖一下。
   - **拇指扳機**：保持手槍手勢，拇指張開後往掌心扣下。

## 技術

- 純單檔 HTML，無後端。
- MediaPipe Tasks Vision (Hand Landmarker) 做手勢辨識。
- Web Audio API 合成背景音樂與所有音效。
- Canvas 2D 繪製畫面、粒子與 VFX。

## 快捷鍵

- `Space / Enter`：開始遊戲或喚醒音效。
- `M`：開關背景音樂。
- `R`：回到開始畫面。
